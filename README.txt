English Class • Anime Presentation Viewer V4

Run locally:
1. Open this folder in VS Code.
2. Open a terminal in this folder.
3. Run: python -m http.server 5501 --bind 127.0.0.1
4. Open: http://127.0.0.1:5501/

V4 keeps the original two presentation decks and adds:
- animated anime-style hero scene
- floating stars/petals
- moving clouds and character
- animated card borders and light sweeps
- smoother viewer entrance and slide motion
- fullscreen presentation mode
- keyboard controls: Left/Right, Space, Home, End, F

For GitHub Pages, upload the contents of this folder with index.html at the repository root.
